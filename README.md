# SaraNajafi

مونوریپوی پلتفرم آموزشی سارا نجفی برای آموزش تخصصی زیبایی مو؛ شامل وب‌سایت Next.js، API ماژولار NestJS، پایگاه‌داده PostgreSQL/Prisma و Redis.

## نیازمندی‌ها

- Node.js 20.19 یا جدیدتر
- pnpm 12.11.2
- Docker Desktop برای اجرای PostgreSQL و Redis

## راه‌اندازی محلی

```sh
pnpm install
cp .env.example .env
docker compose up -d postgres redis
pnpm db:migrate
pnpm db:seed
pnpm dev
```

- وب‌سایت: `http://localhost:3000`
- API: `http://localhost:4000/api/v1`
- بررسی سلامت API و دیتابیس: `http://localhost:4000/api/v1/health`
- فهرست دوره‌ها: `http://localhost:4000/api/v1/courses`

`.env` فقط برای توسعه محلی است. پیش از هر استقرار، رمزهای پیش‌فرض را با مقادیر امن جایگزین کنید.

برای اجرای کامل وب، API و Worker با Docker، پس از مهاجرت دیتابیس اجرا کنید:

```sh
docker compose --profile apps up --build
```

معماری و راهنمای استقرار در `docs/architecture/overview.md` و `docs/deployment/` مستند شده‌اند. پایگاه‌داده و Redis در Compose توسعه روی loopback در دسترس‌اند؛ برای استقرار تولید، راهنمای `docs/deployment/production.md` را دنبال کنید. Worker فعلاً فقط job بررسی سلامت BullMQ را پردازش می‌کند و سامانه برای ظرفیت ۲٬۰۰۰ کاربر هم‌زمان آزمون بار نشده است.

بررسی‌ها: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`. آزمون یکپارچگی API و Worker با دیتابیس و Redis آزمایشیِ جداگانه: `pnpm test:integration`؛ دستورالعمل و محدودیت‌های ایمنی در `docs/deployment/local-development.md` آمده‌اند.

## انتشار فرانت‌اند

صفحه‌های عمومی فرانت‌اند روی GitHub Pages در نشانی [iamradvin.github.io/sara-najafi](https://iamradvin.github.io/sara-najafi/) منتشر می‌شوند. با هر push به شاخه‌ی `main`، GitHub Actions آن‌ها را می‌سازد و منتشر می‌کند. ورود، خرید، پرداخت، پنل‌ها و اتصال به API یا دیتابیس به سرویس‌های سرور نیاز دارند و روی GitHub Pages فعال نیستند.

برای ورود پیامکی، کلید API، کد پترن و خط فرستنده‌ی فراز اس‌ام‌اس را در متغیرهای `FARAZ_SMS_API_KEY`، `FARAZ_SMS_PATTERN` و `FARAZ_SMS_SENDER` در `.env` قرار دهید. ارسال OTP از مسیر پترن فوری انجام می‌شود. مقدار `AUTH_OTP_SECRET` باید یک راز تصادفی حداقل ۳۲ نویسه‌ای باشد. OTP پنج دقیقه اعتبار دارد، پس از پنج تلاش ناموفق قفل می‌شود و ارسال دوباره پس از ۶۰ ثانیه ممکن است. ثبت‌نام و ورود فقط با شماره‌ی همراه و کد پیامکی انجام می‌شوند؛ ثبت‌نام حساب دانشجویی می‌سازد.

## اپلیکیشن‌ها

- `apps/web`: صفحه‌ی اصلی، دوره‌ها و مقالات زیبایی مو، معرفی مدرس، هویت بصری و پنل واکنش‌گرای دانشجو/مدیریت.
- وب‌اپلیکیشن SaraNajafi با manifest و آیکن‌های نصب‌پذیر ارائه می‌شود؛ در توسعه‌ی محلی روی `localhost` و در استقرار روی HTTPS قابل نصب است. Service Worker فایل‌های استاتیک را نگه می‌دارد و هنگام قطع اینترنت فقط صفحه‌ی آفلاین عمومی را نشان می‌دهد؛ صفحه‌های حساب کاربری و API در کش ذخیره نمی‌شوند.
- انتخاب پوسته‌ی روشن/تاریک از هدر وب‌سایت در مرورگر ذخیره می‌شود.
- مسیرهای `/login` و `/register` فقط از کد پیامکی و نشست‌های دیتابیسی با کوکی `HttpOnly` استفاده می‌کنند.
- مسیرهای `/student` و `/admin` و بخش‌های آن‌ها با نشست و نقش کنترل می‌شوند؛ داشبورد مدیریت آمار سفارش‌ها، فروش تأییدشده و دوره‌ها را از دیتابیس می‌خواند و گزارش سفارش‌ها و فهرست دانشجوها را ارائه می‌کند. `/admin/courses` امکان ایجاد پیش‌نویس، ویرایش مشخصات، انتشار و آرشیو امن دوره‌ها را دارد. مدیر از دکمه‌ی «فصل‌ها» می‌تواند فصل‌ها و جلسات را بسازد، ویرایش و مرتب کند. حذف فصل/جلسه‌ای که سابقه‌ی یادگیری دارد برای حفظ سوابق رد می‌شود. داشبورد دانشجو و دوره‌ها، پیشرفت، سفارش‌ها و ویرایش نام و معرفی پروفایل به API و دیتابیس متصل‌اند؛ اعلان‌ها هنوز پیاده‌سازی نشده‌اند.
- برای افزودن دوره، عنوان را وارد کنید تا نشانی آن خودکار ساخته شود، تصویر JPG/PNG/WebP حداکثر ۸ مگابایتی را بارگذاری کنید و فرم را ذخیره کنید. دوره ابتدا پیش‌نویس است؛ فصل‌ها و جلسه‌ها را از دکمه‌ی «فصل‌ها» تکمیل و سپس «انتشار» را بزنید. تصویر جلد در پوشه‌ی `COURSE_UPLOAD_DIR` روی سرور API ذخیره می‌شود؛ در استقرار، این مسیر را روی دیسک پایدار تنظیم کنید. این فایل‌ها تصویر عمومی دوره هستند و برای نگهداری ویدیوهای محافظت‌شده مناسب نیستند.
- `apps/api`: بررسی سلامت، API خواندنی دوره‌های منتشرشده، ثبت‌نام/ورود/خروج، کاربر جاری و گاردهای نشست/نقش؛ API مدیریتی دوره و برنامه‌ی درسی در `/api/v1/admin/courses` و `/api/v1/admin/courses/:courseId/curriculum`، مسیرهای دانشجو در `/api/v1/student/courses` و `/api/v1/student/orders`، مجوز کوتاه‌عمر VdoCipher در `/api/v1/student/lessons/:lessonId/playback`، و checkout زرین‌پال در `/api/v1/checkout`.
- `apps/api/prisma`: مدل کاربران، نقش‌ها و نشست‌ها، دوره‌ها و جلسات، ثبت‌نام، سفارش، پرداخت، پیشرفت و تنظیمات برند.

برای فعال‌کردن تغییرات جدید دیتابیس، سرویس PostgreSQL را اجرا و `pnpm db:migrate` را اعمال کنید. پس از ساخت حساب مدیر، نقش `SUPER_ADMIN` را فقط از طریق دسترسی مستقیم و مورد اعتماد دیتابیس به حساب مدیر اختصاص دهید:

```sql
INSERT INTO "UserRole" ("userId", "roleId")
SELECT u.id, r.id
FROM "User" u
CROSS JOIN "Role" r
WHERE u.email = lower('admin@example.com')
  AND r.name = 'SUPER_ADMIN'
ON CONFLICT DO NOTHING;
```

برای ایجاد یا به‌روزرسانی داده‌های اولیه‌ی محیط توسعه، پس از مهاجرت اجرا کنید:

```sh
pnpm db:seed
```

قیمت دوره را مدیر باید در پنل دوره‌ها تعیین کند؛ تا آن زمان checkout برای دوره‌ی پولی غیرفعال است. برای پرداخت باید `ZARINPAL_MERCHANT_ID` و `ZARINPAL_CALLBACK_URL` تنظیم شوند؛ حالت sandbox به‌طور پیش‌فرض فعال است. برای پخش VdoCipher، مقدار `VDOCIPHER_API_SECRET` را فقط در محیط امن سرور تنظیم کنید. سپس ویدیوها را در پنل VdoCipher بارگذاری کنید و شناسه‌ی ویدیوی VdoCipher را برای هر جلسه در پنل برنامه‌ی درسی مدیر ثبت کنید؛ شناسه و کلید API هرگز نباید URL مستقیم یا در کد مرورگر قرار گیرند. مجوز پخش ۵ دقیقه اعتبار دارد و فقط برای کاربر دارای ثبت‌نام فعال صادر می‌شود. شناسه‌های ویدیوی seed خالی هستند و تا بارگذاری و تنظیم شناسه، پخش غیرفعال می‌ماند. مالک هاست ویدیو باید URLهای عمومی قبلی را نیز غیرفعال کند؛ تا زمان لغو دسترسی عمومی در مبدأ، فایل‌های قدیمی همچنان قابل دانلودند. واترمارک پویا هنوز پیکربندی نشده و باید در مرحله‌ی تنظیم VdoCipher فعال و با حساب مالک بررسی شود. هیچ پخش‌کننده‌ای نمی‌تواند ضبط صفحه یا فیلم‌برداری خارجی را مطلقاً ناممکن کند؛ DRM چندسکویی، مجوز کوتاه‌عمر، واترمارک و کنترل دسترسی فقط ریسک کپی را کاهش می‌دهند. آپلود مستقیم در VdoCipher، مدیریت واقعی سفارش‌ها و ثبت پیشرفت یادگیری هنوز تکمیل نشده‌اند. پرداخت و عملیات دیتابیس نیز باید در محیط دارای PostgreSQL و دسترسی sandbox زرین‌پال end-to-end تست شوند؛ تا آن زمان سامانه را برای استفاده‌ی تولیدی در نظر نگیرید.
